- Automate — workflows, data, and AI-assisted productivity
- Grow — SEO, marketing, content, and outreach

## Deploy to GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. Add your résumé as `resume.pdf`.
4. Update the GitHub URL in `index.html`.
5. Update the email address in `index.html`.
6. Add screenshots and technical details to the project pages.
7. In GitHub, open **Settings → Pages** and select deployment from the `main` branch/root.
8. Open `https://YOUR-USERNAME.github.io`.

## Before publishing

Replace placeholders in the project pages with your real:

- technologies
- screenshots
- GitHub repositories
- architecture diagrams
- measurable results
- mobile app details
- homelab specifications

Do not publish confidential client, institutional, credential, or infrastructure information.
